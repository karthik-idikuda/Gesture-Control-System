# Gesture Control System

Mouse and keyboard control system driven by hand gestures captured through a standard webcam.

## Features

- Cursor movement via index finger tracking
- Click gestures for left and right mouse buttons
- Scroll gestures for page navigation
- Keyboard shortcut gestures

## Tech Stack

Python, OpenCV, MediaPipe, PyAutoGUI

## Getting Started

### Prerequisites

- Python 3.8+
- pip

### Installation

```bash
git clone https://github.com/karthik-idikuda/Gesture-Control-System.git
cd Gesture-Control-System
pip install -r requirements.txt
```

### Usage

```bash
python main.py
```
